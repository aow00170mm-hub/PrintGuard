# 印表機工作 CSV 匯入

## 支援格式

目前支援 SHARP 工作明細 CSV（UTF-8 或 Big5/CP950），已使用 `MX-4140FN_4500014400_20260721.csv` 驗證。

## 匯入方式

1. 網頁「報表分析」頁選擇 CSV 後上傳。
2. 將 CSV 放入 `C:\ProgramData\PrintGuard\imports`，Server 每60秒自動掃描。

自動匯入完成後，成功（包含已去重）的原始檔會移到 `imports\processed`；無法辨識或匯入失敗的檔案會移到 `imports\failed`。兩個資料夾都只保留30天，逾期檔案由 Server 自動刪除。刪除原始 CSV 不會刪除已寫入資料庫的工作紀錄。

## 去重規則

- 檔案層：SHA-256 相同的檔案不重複自動匯入。
- 工作層：使用設備序號、工作ID、帳戶工作ID、開始時間、完成時間及工作模式建立 SHA-256 指紋。
- 不同日期匯出的CSV即使涵蓋重疊期間，同一工作也只會保存一次。

## 報表來源

- `PrintGuard 即時資料`：Windows Spooler Agent 收集。
- `印表機 CSV 匯入`：設備自身產生的成功工作紀錄。
- `兩種來源並列`：同一查詢中並列顯示並標示來源。

兩種來源並列目前不會自動把跨系統工作合併為一筆，因設備紀錄可能只有「無驗證」而沒有AD帳號。避免將合併結果直接作為計費總和；後續可增加跨來源配對及人工確認。

## 成功工作

印表機匯入報表只統計 `結果=OK` 的工作；取消或失敗工作仍保存在資料庫供後續稽核，但不計入成功用量。
